# SIGAP-Sistem-Informasi-Gudang-dan-Pengelolaan-
Praktikum Rekayasa Perangkat Lunak Kelompok 32

## Deskripsi Aplikasi
SIGAP adalah sistem informasi gudang untuk membantu pengelolaan barang dan stok.

## Tujuan Aplikasi
Aplikasi ini dibuat untuk memudahkan proses pencatatan dan pemantauan data gudang.
